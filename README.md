# Progetto CVeDI - Dottor Totem

### Descrizione

**Dottor Totem** è un’interfaccia realizzata per un totem medico ambientato nel contesto futuristico di **StarMed Bay**, una navicella spaziale attrezzata come avamposto sanitario avanzato.
Il progetto è stato sviluppato nell’ambito del corso di Comunicazione Visiva e Design delle Interfacce (**CVeDI**) del corso di Laurea Magistrale di Scienze e Tecnologie della Comunicazione, con l’obiettivo di creare un’esperienza utente rassicurante, accessibile e funzionale per la **gestione delle prenotazioni mediche**.

L’interfaccia è completamente sviluppata in **HTML5**, **CSS3**, **Jason** e **JavaScript**.
- Il sistema totem è pensato per essere visualizzato su schermo con dimensione: **1366 x 1024**.
- Mentre il companino con dimensione: **1600 x 1026**.

---

### Obiettivi

- **Prenotare visite mediche** in modo semplice e rapido.
- **Gestire appuntamenti** esistenti (modifica, cancellazione, visualizzazione).
- **Ridurre l’ansia del paziente** grazie a un’interfaccia user-friendly.
- **Garantire la privacy** dei dati personali e sanitari.

### Struttura del progetto

La cartella principale (`AstroMed`) contiene le seguenti sottocartelle e file:

#### Cartelle:
- `/css`: fogli di stile per il layout e il tema grafico.
- `/data`: dati statici e di test (es. JSON).
- `/fonts`: font personalizzati per l'interfaccia.
- `/icons`: set di icone per la navigazione e le azioni.
- `/img`: risorse grafiche e illustrazioni.
- `/js`: script JavaScript per le funzionalità dinamiche.
- `/new-booking`: pagine per il flusso guidato alla prenotazione di una visita.

#### File principali:
- `index.html`: schermata di login di accesso.
- `home.html`: home utente con panoramica delle funzionalità.
- `appointments.html`: gestione e visualizzazione appuntamenti.
- `dossier.html`: accesso al proprio fascicolo sanitario.
- `info-doctor.html`: dettagli relativi a uno specifico medico.
- `informations.html`: servizi offerti dall’ospedale.
- `map-info.html`: mappa dell’ospedale e localizzazione degli ambulatori.
- `profile.html`: profilo utente con dati personali e assicurativi.
- 'new-booking...html': flusso di pagine per la prenotazione di una visita medica.
